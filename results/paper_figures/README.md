# Centralized Publication Figures: Palomero et al. (2026)

This directory serves as the single source of truth for all publication-ready figures generated by the modular simulation pipeline of **Palomero et al. (2026)** (*BRCA1-ONSET*).

Every figure is provided in three standardized publication formats:
- **PDF** (`.pdf`): Publication vector format (PDF 1.4 / Type 42 fonts).
- **EPS** (`.eps`): Encapsulated PostScript vector format for journal print workflows.
- **PNG** (`.png`): High-resolution (300 DPI) raster graphics for rapid review.
